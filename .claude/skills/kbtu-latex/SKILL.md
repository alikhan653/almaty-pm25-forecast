# KBTU LaTeX Thesis Skill

Generates a complete XeLaTeX thesis project for KBTU master's theses following
GOST 7.32-2017 and KBTU 7M06106 programme requirements.

## When invoked

1. Read `requirements/formatting.md` and `requirements/kbtu_structure.md` for
   current binding constraints.
2. Read `thesis/*.md` to understand the current chapter structure.
3. Generate `thesis/main.tex` using the template in `templates/kbtu_thesis.tex`
   as the base, populated with the actual thesis title, author, and chapter files.
4. Generate per-chapter `.tex` stubs if needed (convert from Markdown using
   the pandoc command in §Conversion below).
5. Test-compile with `xelatex` and report any errors.

## GOST 7.32-2017 formatting rules (hard constraints)

| Parameter | Value |
|---|---|
| Engine | XeLaTeX (required for Unicode + Times New Roman) |
| Paper | A4, portrait |
| Margins | left 30 mm, right 10 mm, top 20 mm, bottom 20 mm |
| Body font | Times New Roman 14 pt |
| Line spacing | Single (`\setstretch{1.0}`) |
| First-line indent | 1.25 cm |
| Heading L1 | 16 pt, bold, centred, ALL CAPS, `\newpage` before |
| Heading L2 | 14 pt, bold, left-aligned |
| Heading L3 | 14 pt, bold italic, left-aligned |
| Page numbers | Bottom centre, 12 pt, continuous from title page |
| Table captions | ABOVE table, left-aligned, `Таблица X.X – Title` |
| Figure captions | BELOW figure, centred, `Рисунок X Title` |
| Equations | Centred, number at right margin in parentheses |
| Bibliography | APA 7th edition via `biblatex` + `biber` |

## Conversion: Markdown → LaTeX

Convert a chapter markdown file to LaTeX with:
```bash
pandoc thesis/chapter_1_review.md \
  --from markdown --to latex \
  --output thesis/tex/chapter_1_review.tex \
  --wrap=none
```

Repeat for each chapter. Then `\input` them in `main.tex`.

## Compilation

```bash
cd thesis
xelatex main.tex
biber main
xelatex main.tex
xelatex main.tex   # third pass for TOC and cross-refs
open main.pdf
```

If `xelatex` is not available: `brew install --cask mactex-no-gui`

## File layout produced

```
thesis/
  main.tex          ← master file (generated by this skill)
  references.bib    ← existing BibTeX (already present)
  tex/
    abstract.tex
    introduction.tex
    chapter_1_review.tex
    chapter_2_methodology.tex
    chapter_3_implementation.tex
    chapter_4_discussion.tex
    conclusion.tex
```

## Template location

The base LaTeX template is at `templates/kbtu_thesis.tex` in this skill
directory. When generating `thesis/main.tex`, substitute the placeholders:
- `<<TITLE_EN>>` — English thesis title
- `<<TITLE_RU>>` — Russian thesis title
- `<<AUTHOR>>` — Author full name
- `<<SUPERVISOR>>` — Supervisor name + degree
- `<<YEAR>>` — Defence year
